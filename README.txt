MONNY — файли сайту

index.html — головна сторінка
style.css — стилі та адаптивне оформлення
app.js — каталог, фільтри, обране, локації, демоколесо та форма підтримки
assets/ — усі зображення

Розпакуйте архів повністю й відкрийте index.html у браузері. Зберігайте структуру папок. Для Google Maps та Google Fonts потрібне підключення до інтернету.

Локації позначені як кандидати. Підтримка створює локальний текст звернення без відправлення. Обране зберігається у браузері.
